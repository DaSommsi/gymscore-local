# Benutzerhandbuch — GymScore Local

Willkommen bei **GymScore Local**, dem digitalen Wettkampf- und Aufnahme-Assistenten für Schulsporttage. Dieses Handbuch führt Sie durch den Ablauf von der Vorbereitung bis zur Siegerehrung.

---

## 📋 1. Vorbereitung vor dem Sporttag

### 1.1 Teilnehmerliste vorbereiten (Excel)
1. Starten Sie GymScore Local auf dem Laptop.
2. Wechseln Sie zum Reiter **Teilnehmerliste**.
3. Klicken Sie auf **Vorlage**, um die vorgefertigte Excel-Tabelle herunterzuladen.
4. Tragen Sie Ihre Schülerinnen und Schüler in die Datei ein:
   - `Startnummer`: Eindeutige Nummer (z. B. `101`, `102` oder `501`)
   - `Vorname` & `Nachname`
   - `Geschlecht`: `M`, `W` oder `D`
   - `Geburtsjahr`: z. B. `2014`
   - `Klasse`: z. B. `5A`
5. Klicken Sie auf **Excel importieren** und wählen Sie die gespeicherte Datei aus. Alle Schüler erscheinen sofort in der Tabelle.

---

## 🏃 2. Durchführung in der Turnhalle

### 2.1 Helfer verbinden
1. Klicken Sie in der oberen Leiste auf **Helfer QR-Code**.
2. Projizieren Sie den QR-Code auf einen Monitor / Beamer oder lassen Sie die Stationsleiter den Code direkt vom Laptop-Bildschirm scannen.
3. Die Helfer öffnen die Web-App auf ihrem Smartphone.

### 2.2 Wertung erfassen
1. Der Helfer wählt oben seine Station (z. B. *Standweitsprung*).
2. Der Schüler nennt seine Startnummer (z. B. *105*).
3. Der Helfer tippt `105` ein – sofort erscheint zur Sichtprüfung: **"Lukas Weber • Klasse 5B"**.
4. Der Helfer gibt den Messwert über den großen Ziffernblock ein (z. B. `185` cm).
5. Klick auf **Ergebnis speichern**. Die Daten werden in Sekundenbruchteilen auf den Laptop übertragen.

---

## 📊 3. Abschluss & Auswertung

### 3.1 Live-Überwachung
- Während des Events zeigt der Reiter **Live-Übersicht** den prozentualen Fortschritt aller Stationen (z. B. *42 von 50 Schülern am Sprint abgeschlossen*).
- Fehleingaben können im Reiter **Ergebnisse & Audit** mit einem Klick auf den Papierkorb korrigiert oder gelöscht werden.

### 3.2 Excel-Gesamtexport
- Klicken Sie oben rechts auf **Excel-Export**.
- Sie erhalten eine fertige Excel-Tabelle mit allen Schülern, Klassen und den jeweils besten Werten jeder Station, geordnet nach Startnummern.
